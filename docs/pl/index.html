Claude, ChatGPT, Gemini lub własny agent LLM — może korzystać bez udziału człowieka, po jednorazowym kroku wykonanym przez człowieka: rejestracji konta i przekazaniu agentowi klucza API, tokenu OAuth lub połączenia z serwerem MCP (Model Context Protocol). Każdy wpis zawiera adres dokumentacji, metodę uwierzytelniania, dostępność oficjalnego lub społecznościowego serwera MCP oraz darmowy limit. Nie jest to spis produktów z „AI” w nazwie — kryterium jest możliwość obsługi przez agenta, a nie marketing.

Kryteria włączenia

  1. Usługa udostępnia publiczny, samoobsługowy interfejs programowy (REST, GraphQL, SDK) lub serwer MCP.
  2. Człowiek musi działać najwyżej raz — założyć konto i wygenerować klucz lub zatwierdzić OAuth. Potem agent działa samodzielnie.
  3. Interfejs jest udokumentowany i aktywny (linki sprawdzono w dniu podanym w infoboksie).
  4. Aplikacje wyłącznie konsumenckie, listy oczekujących, produkty dostępne tylko przez dział sprzedaży, frameworki agentów i IDE są wykluczone — to agenci lub narzędzia do ich budowy, a nie usługi wywoływane przez agenta.

Powiązane katalogi i rejestry

Inne czytelne maszynowo źródła, w których agenci mogą wyszukiwać narzędzia:

  • Official MCP Registry — Oficjalny rejestr Model Context Protocol; agenci mogą wywoływać jego API REST (ze specyfikacją OpenAPI), aby wyszukiwać i listować dostępne serwery MCP. — JSON/API
  • public-apis/public-apis — Prowadzona przez społeczność lista ponad 1400 darmowych publicznych API na GitHubie, dostępna jako surowy plik Markdown do parsowania programistycznego. — JSON/API
  • APIs.guru OpenAPI Directory — Otwarty, niewymagający uwierzytelniania katalog ponad 2500 publicznych specyfikacji OpenAPI; agenci pobierają list.json, aby odkryć API i ich definicje OpenAPI. — JSON/API
  • punkpeye/awesome-mcp-servers — Popularna, prowadzona przez społeczność lista serwerów MCP na GitHubie, dostępna jako surowy Markdown do automatycznego odkrywania. — JSON/API
  • Smithery — Rejestr i brama hostingowa serwerów MCP (ponad 6000 pozycji), której API REST pozwala agentom wyszukiwać serwery i uzyskiwać adresy połączeń. — JSON/API
  • Glama MCP Directory — Duży, skanowany i oceniany rejestr ponad 90000 otwartoźródłowych serwerów MCP, dostępny przez API REST z uwierzytelnianiem bearer. — JSON/API
  • mcp.so — Społecznościowy marketplace i przeglądalny katalog serwerów MCP, jednak nie posiada publicznie udokumentowanego API JSON/REST do dostępu programistycznego.
  • PulseMCP — Katalog ponad 21800 serwerów MCP aktualizowany codziennie; jego API REST typu Sub-Registry (wymaga klucza API) pozwala agentom listować i wyszukiwać serwery. — JSON/API
  • llms.txt convention / directory — Otwarta konwencja pliku llms.txt w katalogu głównym witryny, dająca agentom zwięzłą mapę w Markdown kluczowych treści strony; społecznościowy katalog indeksuje opublikowane pliki, choć nie udostępnia API JSON. — JSON/API
  • Postman API Network — Największa sieć publicznych kolekcji API udostępnianych na Postman, przeglądalna w sieci, lecz bez udokumentowanego publicznego API do programistycznego odkrywania.
  • RapidAPI Hub (Nokia API Hub) — Duży marketplace API firm trzecich z rosnącym wsparciem dla MCP dla agentów, lecz bez publicznego, niewymagającego uwierzytelniania punktu końcowego do masowego odkrywania.
