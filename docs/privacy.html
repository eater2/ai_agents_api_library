Privacy policy

This policy covers the website https://ai-agents-api-library.vercel.app/, the hosted MCP server at https://ai-agents-api-library.vercel.app/mcp, the npm package ai-agents-api-library and the Claude Code plugin of the same name.

What we collect

  • No accounts, no cookies, no analytics or tracking scripts.
  • MCP server: for each request the server writes one log line with the MCP method, the tool name and the category filter, for usage statistics. Search queries, service ids and other arguments are not logged or stored.
  • Hosting: the site and the server run on Vercel, which keeps standard request logs (such as IP address, time, URL and user agent) for a limited time; see the Vercel privacy policy. The static catalog files are also served by GitHub; see the GitHub privacy statement.
  • npm package and plugin skill: run on your machine and read the bundled catalog; they send nothing to us.

Third-party services

The catalog lists other companies' APIs. If you or your agent call one of them, that call goes directly to that company under its own terms and privacy policy. This project never receives your API keys.
