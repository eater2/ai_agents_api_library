**AI Agents Accessible APIs** (pol. *API dostępne dla agentów AI*) to otwarty, dwujęzyczny (angielski/polski) katalog **330 zweryfikowanych usług** w **27 kategoriach**, z których autonomiczny agent AI — np. Claude, ChatGPT, Gemini lub własny agent LLM — może korzystać **bez udziału człowieka**, po jednorazowym kroku wykonanym przez człowieka: rejestracji konta i przekazaniu agentowi **klucza API**, **tokenu OAuth** lub połączenia z **serwerem MCP (Model Context Protocol)**. Każdy wpis zawiera adres dokumentacji, metodę uwierzytelniania, dostępność oficjalnego lub społecznościowego serwera MCP oraz darmowy limit. Nie jest to spis produktów z „AI” w nazwie — kryterium jest możliwość obsługi przez agenta, a nie marketing.

## Kryteria włączenia

- Usługa udostępnia **publiczny, samoobsługowy** interfejs programowy (REST, GraphQL, SDK) **lub** serwer MCP.
- Człowiek musi działać **najwyżej raz** — założyć konto i wygenerować klucz lub zatwierdzić OAuth. Potem agent działa samodzielnie.
- Interfejs jest **udokumentowany** i **aktywny** (zweryfikowano w dniu podanym w infoboksie).
- Aplikacje wyłącznie konsumenckie, listy oczekujących, produkty dostępne tylko przez dział sprzedaży, frameworki agentów i IDE są **wykluczone** — to agenci lub narzędzia do ich budowy, a nie usługi wywoływane przez agenta.

## Legenda

- **MCP ✅** — oficjalny serwer MCP utrzymywany przez dostawcę
- **MCP ◐** — serwer MCP utrzymywany przez społeczność
- **MCP —** — brak znanego serwera MCP; należy użyć REST API
- **🆓** — darmowy limit lub użycie bez opłat
- **★ (data)** — dowód pod nazwą usługi: ocena i liczba opinii z SourceForge, gwiazdki GitHub, użycia w Smithery — z linkiem i datą pobrania

- [public-apis/public-apis](https://github.com/public-apis/public-apis) — Prowadzona przez społeczność lista ponad 1400 darmowych publicznych API na GitHubie, dostępna jako surowy plik Markdown do parsowania programistycznego. — machine-readable: <https://raw.githubusercontent.com/public-apis/public-apis/master/README.md>
- [APIs.guru OpenAPI Directory](https://apis.guru) — Otwarty, niewymagający uwierzytelniania katalog ponad 2500 publicznych specyfikacji OpenAPI; agenci pobierają list.json, aby odkryć API i ich definicje OpenAPI. — machine-readable: <https://api.apis.guru/v2/list.json>
- [punkpeye/awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers) — Popularna, prowadzona przez społeczność lista serwerów MCP na GitHubie, dostępna jako surowy Markdown do automatycznego odkrywania. — machine-readable: <https://raw.githubusercontent.com/punkpeye/awesome-mcp-servers/main/README.md>
- [Smithery](https://smithery.ai) — Rejestr i brama hostingowa serwerów MCP (ponad 6000 pozycji), której API REST pozwala agentom wyszukiwać serwery i uzyskiwać adresy połączeń. — machine-readable: <https://api.smithery.ai/servers>
- [Glama MCP Directory](https://glama.ai/mcp/servers) — Duży, skanowany i oceniany rejestr ponad 90000 otwartoźródłowych serwerów MCP, dostępny przez API REST z uwierzytelnianiem bearer. — machine-readable: <https://glama.ai/api/mcp/v1/servers>
- [mcp.so](https://mcp.so) — Społecznościowy marketplace i przeglądalny katalog serwerów MCP, jednak nie posiada publicznie udokumentowanego API JSON/REST do dostępu programistycznego.
- [PulseMCP](https://www.pulsemcp.com) — Katalog ponad 21800 serwerów MCP aktualizowany codziennie; jego API REST typu Sub-Registry (wymaga klucza API) pozwala agentom listować i wyszukiwać serwery. — machine-readable: <https://api.pulsemcp.com/v0.1/servers>
- [llms.txt convention / directory](https://llmstxt.org) — Otwarta konwencja pliku llms.txt w katalogu głównym witryny, dająca agentom zwięzłą mapę w Markdown kluczowych treści strony; społecznościowy katalog indeksuje opublikowane pliki, choć nie udostępnia API JSON. — machine-readable: <https://directory.llmstxt.cloud>
